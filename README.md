# EPUB Translate Bot — Fast

Telegram bot for translating EPUB novels/books.

## Features

- EPUB upload
- Multiple languages
- Fast batch translation
- Parallel translation workers
- Automatic retry
- Exponential backoff
- Progress bar
- Estimated time
- Used time
- File word count
- Translated words
- Remaining words
- Words per second
- EPUB validation
- Images preserved
- CSS preserved
- Chapter structure preserved
- Metadata translation
- Cancel button
- Render health endpoint
- Python 3.12 support
